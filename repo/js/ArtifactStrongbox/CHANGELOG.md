# 更新记录

当前实现版本：**0.9.3**。文档整理日期：2026-10-29。此次整理不改变版本号或运行逻辑。

## 0.9.3

- 遮罩顶部加入默认开启的“受现有套装限制”；可关闭后对照属性评分。
- 切换时重算逐角色三色标签及顶部计数；强化样本保持一致。
- 关闭时仍检查主词条范围、同部位现装归属与完整性，不计入套装效果损失。

## 开发阶段记录

以下保留各版本当时的描述，部分限制已被后续版本替代。当前操作与行为以 [README](README.md) 和 [当前判据](docs/role-assessment.md) 为准。

- **0.9.3可选现装套装限制**：顶部“受现有套装限制”默认开启；关闭后跳过拆套装检查，仅作属性评分对比，重新计算三色标签和计数。见 [开关说明](docs/set-restriction-toggle.md)。
- **0.9.2三色计数**：顶部改为舍弃/待定/保留角色数，同角色多分支去重，重算时清除旧计数。核验原评分小攻击的基础攻击折算，见 [计数与固定词条实例](docs/summary-and-flat-stats.md)。
- **0.9.1主词条规则**：沙/杯/冠只考虑>15%的已录入主属性推荐；可靠不匹配对该角色判舍弃。跨推荐主属性须计入双方主副总分，明显落后才判舍弃，无法计价则待定。见 [主词条适配与计分](docs/main-stat-policy.md)。
- **0.9.0逐角色取舍与容量估计**：新增0～2700静态总量配置；保留套装约束、同主词条和可靠+20现装前提下，按推荐秩及原规则核验显示绿保留/红舍弃/黄待定。顶部仍待人工判断。见 [逐角色判据与范围](docs/role-assessment.md)。
- **0.8.1改善选人与搜索**：独立宽面板、按元素分组与标签、中文/全拼/首字母搜索；固定134项拼音索引，大号金色F7提示。见 [元素选人与搜索](docs/character-search-ui.md)。套装替换与推荐秩权重仅讨论，见 [取舍方案](docs/disposal-and-rank-discussion.md)。
- **0.8.0接入已录入推荐数据**：三合一默认合并套装适配与培养角色，可选按沙/杯/冠主词条补充散件候选；遮罩按元素勾选角色、滚动查看全部分位数。按F7切换交互。见 [三合一候选与推荐数据](docs/strongbox-recommendations.md)。
- [项目进度与开发交接](docs/project-status.md)：已实现功能、已知评分问题、用户约束和后续顺序。
- [账号采集参考与状态设计](docs/account-capture-design.md)：最新 `15:22:11` 录制的 44 个操作、八张参考图、候选区域、五件人工对照及循环边界。
- **0.5.0已加入可选角色仓库录入**，见 [录入使用说明](docs/account-capture-usage.md)。只有右下角装备者可靠匹配当前角色，才能写入现装；空部位默认选中的背包物品不能冒充现装。
- **0.5.1调整录入节奏和日志**：动作等待600毫秒、稳定帧复核120毫秒；按阶段减少OCR范围，直接复用详情确认结果。日志列出角色、部位、物品名和推荐摘要。
- **0.5.2修复识别容错与套装点击**：右侧完整区域识别，首次失败重新点击一次并聚焦重读；装备者按行提取；只点使用率不低于10%的推荐，“×4”不清也会尝试读取套装名。
- **0.6.0增加拟培养角色选择**：按用户标识保存，已录入角色优先展示，可搜索补选评分库中的角色。三合一仅计算所选角色，不再默认全库排名，见 [角色选择说明](docs/training-characters.md)。
- **0.6.1修复返回概览身份误判**：概览使用左上完整标题，属性页双来源复核；不一致先回属性确认。新增按账号、按运行保存的动作与OCR日志，定位方法见 [运行日志说明](docs/runtime-logging.md)。
- **0.6.2完善姓名识别**：调整重试裁剪、处理分隔符漏读与独立斜杠框误读、重试后按多帧交叉证据确认；过滤异常等级。日志改用BGI允许的JSON分片并回读校验，补充控制台具体姓名读数。
- **0.7.2修复姓名字母混入与完整性判断**：字典名优先于未匹配OCR；无装备者标记不录为当前装备；确认套装种类后补全4件套或2＋2件数；跳过选项仅跳过完整角色。见 [录入完整性与姓名容错](docs/capture-quality.md)。
- **0.7.0加入7.1名称字典、简介身份归一化及跳过已有数据**：修正生僻字OCR，按介绍识别流浪者、人偶A/B和旅行者，保留账号别名；已备份更正历史错名。见 [名称与增量录入说明](docs/character-names.md)。
- **0.7.1补齐旅行者七元素**：统一显示“旅行者（风/岩/雷/草/水/火/冰）”，不区分男女，按当前元素核验别名和装备者。现有冰主权重已接入候选；新增旅行者参考图与OCR预处理实验，见 [旅行者和OCR处理说明](docs/traveler-and-ocr.md)。
