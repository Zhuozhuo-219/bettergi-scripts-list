# 主词条范围与跨主词条比较（0.9.1）

更新：2026-10-28。本次补充逐角色判据，顶部整件仍为待人工判断。

## 主词条使用率严格高于15%

时之沙、空之杯、理之冠只将该角色该部位已录入、使用率**>15%**的推荐主词条视为本次用途范围，15.0%不包含，15.1%包含。生之花和死之羽主属性固定，不套用该门槛。

推荐须状态ok、具有主属性标题、合法名称/单位、连续秩次、降序且0～100的使用率；总使用率明显异常则待定。排除缺项还要求读到三行，或少量行累计使用率足够高（≥85.15%，含舍入余量）。只有一行70%时，可正向确认这行适配，但不能把未读到的其他属性全部判为不适配。无任何>15%属性时也不一刀切舍弃，先核对推荐。

可靠推荐范围之外的主词条，对本角色直接标红“舍弃”，原因明确为`main-not-recommended`。这是用户指定的用途过滤，不是假称模拟得到0%提升概率。它优先于拆套装或缺少现装基准；只需要素材+0且识别无警告、角色身份已确认和推荐可靠。缺少旧评分权重的角色也能执行该范围排除，但数值列仍显示破折号。

非0级素材或主词条/推荐不可靠时保持待定。红色结论仅覆盖该角色和>15%的用途范围，不否定低使用率流派、其他角色或账号未来用途。

“主词条适配（>15%）”开关控制是否从主属性推荐新增散件候选；不控制已经从培养名单/套装入选的角色是否执行主词条适用性检查。

## 两个主词条都适配时

素材和现装主词条相同时，主属性贡献相互抵消，沿用原副词条增量比较。

若主词条不同，先满足可靠+20现装、五部位归属和不拆套装。只有两种主属性都能用现有词条单位计价，且三模型均对其有正权重时，才计算：

`总分 = 副词条标准化分 + 主属性权重 × +20主属性值 / 该属性最高单次副词条档位`。

双方各用自己的满级主属性数值，模型权重按同一角色用途冻结。基线也必须计入主属性，不能只给素材加分或把不同主词条视为等价。例如生命沙与充能沙可在具有对应权重时按此标准化单位比较。

伤害加成、治疗加成等没有对应副词条档位；若两个推荐主词条之一无法计价，或某情景没有合理正权重，标记待定`main-unpriced`。不能把无法估价的主属性当作0分。不同主词条的行悬停可查看>15%的接受范围，可计价行还显示“主＋副”。

跨主词条的舍弃要求比原规则更严格：除原来的三模型正提升概率上界均≤1%外，还要求三模型中“能进入现装半档核心词条以内”的概率上界均≤1%。即分布上尾也须存在清晰劣势，而非仅略低一点。幅度门槛为0.5个最高档核心词条单位，仍以Wilson保守界处理模拟误差。模型分歧、间距不足均待定。

保留仍要求三模型下至少提升0.5单位的概率下界均≥80%。这是试行属性预算评分，不是精确伤害或已校准后验。

## 主词条会怎样影响副词条

固定角色权重时，同样副词条数值的基础加权分不会因为换了主词条而凭空改变。但主词条会影响：

- **合法词条池**：不能出现同名同类型副词条。暴率冠没有暴率副词条，改成其他主词条后则可能有。
- **总属性预算**：强主属性可能补偿一部分副词条差距，仅看副词条会偏向错误主词条。
- **真实边际收益**：换暴率/暴伤冠可能改变双爆平衡，充能主属性也可能改变充能需求缺口；无角色面板时，本模型不声称准确模拟这些非线性效应。

因此采用“推荐范围过滤→可计价的主副总分→保守分布差距”，而不是对所有不同主词条统一待定，也不直接用旧数值列的差距证明跨主属性优劣。
