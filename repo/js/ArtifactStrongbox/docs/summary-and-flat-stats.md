# 三色概括计数与固定数值词条核验（0.9.2）

更新：2026-10-28。本次改动顶部概括显示，不改变0.9.1逐角色判据或评分权重。

## 顶部计数

原“待人工判断”位置改为红色舍弃、黄色待定、绿色保留三个计数卡。范围是当前已开启来源实际参与分析的角色；同角色多来源、多评分分支只计一次。

- 任一分支保留：该角色计保留。
- 无保留且有待定、缺少权重或未完成分支：计待定。
- 全部分支舍弃：计舍弃。可靠的主词条范围排除与分支权重无关，可独立计入舍弃。

正在计算、识别不完整或离开素材界面时清除旧计数，以破折号表示尚无有效结果。有效分析但没有候选时显示三个0和“本次无分析角色”。源计数中的套装/培养/主词条可以重叠，而顶部三色计数互斥，三者之和为角色总数。

这些计数只是用途结果概括，不输出整件圣遗物的最终取舍。展开或滚动仍可查看分支明细；说明中注明按角色去重。日志`strongbox.assessments.summary`同步记录统计与每角色归类。

## 原评分如何处理小攻击

已核对原`ArtifactScore/utils/artis-score-standalone.js`的`buildAttrs`（3736行起）与本项目派生快照一致；本次未修改原文件或vendor。

固定攻击力`atkPlus`的基础类型为`atk`，继承攻击百分比的角色权重。固定生命`hpPlus`继承`hp`，固定防御`defPlus`继承`def`。若对应百分比属性权重为0，固定值属性也不会获得分数。

对于小攻击，原始未归一化系数为：

`atkPlus.mark = 攻击权重 / 原评分最高档攻击百分比 / (库中角色基础攻击 + 武器基础攻击假设) × 100`。

等价理解是将固定攻击换成攻击百分比：

`等效攻击% = 固定攻击 / (角色基础攻击 + 武器基础攻击) × 100`。

分母不是总攻击面板。`buildAttrs`的默认武器基础攻击为520，而普通`calcArtifactScore`入口没有传入实际武器基础攻击，所以仍用520；角色基础攻击来自本地`baseAttrMap`，不是本账号识别面板。这是原评分的近似条件。

## 香菱的本地快照实例

原库中香菱基础攻击282.58，默认武器基础攻击520，攻击权重75。因此固定攻击19等效于：

`19 / (282.58 + 520) × 100 = 2.367365%`。

用原评分函数对相同精通主词条时之沙作控制变量比较：主词条精通187，共同副词条暴率3.9%、暴伤7.8%、充能6.5%，只考察额外一条属性带来的边际分数。此处演示线性计分贡献，不将控制项当作实际强化成品。

| 额外词条 | 原评分边际增分 |
| --- | ---: |
| 固定攻击+19 | 约1.675741 |
| 攻击力+5.8% | 约4.105534 |

比值约40.8166%。两者字段上都继承攻击权重75，但固定攻击换算后的最高档有效权重更低，因此不能只看字段`weight`就认为每次词条同分。最终分数还受部位理论上限和主词条修正系数影响，以上增分不能移用于其他角色/部位。

固定生命和防御按相同思路除以角色对应基础值，通常没有武器基础攻击这一项。例如本地芙宁娜攻击权重0，所以大小攻击均计0；固定生命则可继承非零生命权重。

## 与新秩模型的区别

当前推荐线性/指数秩只给已列入追加属性推荐的键赋权，严格区分百分比与固定值。推荐若只有“大攻击”，小攻击在这两个模型中暂不自动继承。但第三个“原规则敏感性核验”情景仍保留旧规则的小攻击折算。

本轮仅核验和说明该差异，未自行决定是否将折算扩展到新秩模型。复现可运行`node tools/inspect-flat-weights.mjs`，只读调用原规则，不读取或写回账号。
