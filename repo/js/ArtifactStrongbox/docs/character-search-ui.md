# 元素选人与拼音搜索（0.8.1）

更新：2026-10-27。评分、候选匹配与取舍规则未改动。

按F7进入交互后，右侧点击“选择拟培养角色”，在宽970像素的独立面板中选择，角色区不再挤占390像素的评分栏。默认按已录入元素分组，可用顶部元素标签只看某一元素；四列角色卡片、独立滚动区和搜索框支持较大角色库。搜索新词会回到全部元素，避免被之前的标签意外隐藏结果。按“完成选择”仅收起面板，F7或“返回游戏”切回游戏并收起面板。

独立的BGI“选择拟培养角色”窗口也改为按元素分组、元素标签与较宽布局，已录入角色优先采用记录中的元素，其他角色使用既有本地角色规则库的元素。

两个选择界面均支持中文、无声调全拼、首字母、大小写、拼音空格及常见带音调输入。如“纳西妲 / naxida / NXD”、“菈乌玛 / lawuma / lwm”；白术、重云、行秋等兼容多音字常见输入。旅行者保留元素区别，人偶A/B保留各自后缀，不因搜索改变角色身份。

`assets/character-search.json`保存134个名称的固定索引，包含7.1名称字典全部条目、七元素旅行者和人偶A/B。开发脚本`tools/build-character-search.py`使用MIT许可的[pypinyin](https://github.com/mozillazg/python-pinyin) 0.55.0一次生成，记录生成器版本、名称字典SHA256及多音字搜索别名；BGI运行时只读JSON，不依赖Python、在线服务或额外拼音库。名称字典更新后重跑生成器，再执行完整回归。

开发环境命令示例（请在开发环境安装pypinyin==0.55.0，普通脚本用户无需安装）：

```text
python tools/build-character-search.py
node tools/verify-all.mjs
```

F7提示改为标题下方的金色大按键和高对比状态栏，随右侧标题保持在顶部。切回游戏时同步通知HTML收起选人面板；选择仍按原账号文件自动保存。

离线验证覆盖字典来源哈希、134项完整性、生僻字/多音字、两种界面的拼音与首字母、元素标签、面板收起与原功能回归。使用本机Edge渲染检查布局，仍需BGI/WebView2游戏内体验确认。

关于配装约束、现装提升概率和推荐秩权重，仅记录在 [取舍与秩评分讨论](disposal-and-rank-discussion.md)，本版本没有启用。
