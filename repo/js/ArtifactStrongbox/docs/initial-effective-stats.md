# 初始有效副词条阈值（0.9.4）

更新：2026-11-08。这是由玩家选择的初筛规则，用于在缺现装、拆套装等比较条件导致待定时，直接排除初始有效副词条过少的角色用途，不是由模拟分数推导的概率结论。

## 操作

按F7进入遮罩交互，勾选「排除初始有效词条数阈值」，显示离散滑动条0、1、2、3、4。默认关闭，阈值默认2，均只在本次运行有效。

严格比较「计数 < 阈值」：阈值2排除0／1条，2条继续原判据；阈值0不排除任何用途。关闭后恢复原有取舍，达到阈值不直接判保留。

## 计数定义

- 仅统计+0时**已激活**的副词条种类。初始三条最多计3条，灰色待激活第四条不计，即使已知道其名称与数值。主词条不计。
- 有效性来自该角色、该部位已确认的游戏内「推荐追加词条」，不使用另一部位或另一角色的推荐，也不自动继承原评分库中的小攻击等非零权重。
- 暴击率与暴击伤害分别计1条，不因评分中同权分组而合为1条。固定生命／攻击／防御与对应百分比分开，元素精通仍为固定值。
- 每个角色分别计数；相同物品可能对角色A为0条、角色B为2条。重复来源不重复计数，多评分分支共用该角色推荐。
- 名称身份、素材数值、四条激活状态、推荐种类／单位／秩次需可靠。推荐标题或数据缺失时计数未知，不伪造为0条；原有规则仍可继续给出独立判定。

## 与其他规则的关系

顺序为素材及身份保护 → 可选初始有效词条初筛 → 原主词条范围 → 现装和套装约束 → 三情景强化比较。

初筛低于阈值时无需满级现装或全套装备资料，也不要求替换能够保留原套装组合。无旧评分权重的角色，只要已有可靠推荐，仍能作此初筛，分位数保留空值。非+0、OCR警告或数值异常不会被此规则判舍弃。

该规则覆盖同角色各评分分支，独立于原分支能否计算；顶部按角色计入红色数。仍只覆盖已开启来源中的候选，不变成整件物品的自动丢弃决定。

## 显示、日志与缓存

开启时各行显示「初始有效 N/M」（M为已激活副词条总数），悬停显示有效名称、未计入的待激活有效数及阈值。命中初筛的原因明确写出玩家规则，不显示虚构的提升概率。

筛选事件日志记录开关和阈值；计算日志保留初筛原因和计数。缓存包含开关、阈值及识别保护状态；切换后重算标签和顶部计数，模拟样本与原分位数不变。

`node tools/verify-all.mjs`包含计数、0～4边界、待激活／单位／双爆、无现装／拆套装、缺评分分支、非法设置、缓存、HTML通信及真实入口传参验证。仍需在BGI内核验交互和实图OCR。
