# 修订模型实现记录

2026-11-18，版本0.10.0。数学依据为同目录的 `genshin_artifact_model_revised.tex` 及对应PDF。本次完成P0概率引擎、用途价值与整件仲裁，并接入已有装备快照支持的局部配装搜索。

## 计算与数值

`artifact-distribution.js`采用16项单步强化核的有限卷积。概率质量用整数路径数累计，分母为16的q次方。q最多5。已知待激活第四条已经包含在确定性基线中，激活不增加随机次数。

单步评分增量以1e-8为网格，累计评分量化误差至多q×0.5e-8。每件成品的显示值仍含游戏显示取整误差。概率、期望、方差、正提升收益和分位数从同一PMF计算。严格超越使用大于号，同时保留大于等于尾概率。阈值附近的量化误差以概率界和收益界记录。

分布缓存按权重增量及q复用，确定性基线单独叠加。角色来源、低词条提示和套装开关变化会重新仲裁，已经计算的同核卷积可以复用。模拟器保留作开发对照，正常入口采用卷积。

## 价值与配套证据

保留推荐线性秩、指数秩和原权重核验三情景。固定同一角色上下文后，比较素材满级分数与有效替换门槛，计算严格超越概率p及期望正提升U。

收益线由JS设置提供。保留线默认0.5，低价值线默认0.05，单位为核心属性最高档。这两个数是实现时选择的试行默认值，数学文档未指定数值。三情景收益区间全部达到保留线时保留，全部低于低价值线时记低价值，中间区域建议试强化。已有资料不足时单列核对原因。

装备池仅纳入角色身份、装备者、部位、数值、新鲜度可靠的满级观察。先固定每个部位原有主词条，枚举原四件套或2+2件数要求下的合法组合，分别求不使用素材和强制使用素材的最优属性总分，得到有效替换门槛。可以改变散件部位。方案涉及其他角色的已装备物品时显示调配提示，日志和悬停保留配套来源。

此处为单角色、已观察装备池的局部求解。多角色同时争用同一件装备、全背包最优配装、替换目标套装的非线性效果仍待库存阶段实现。缺配套候选时保留属性潜力及需配套证据，主属性无法统一计价时需核对。

## 潜在词条与四种建议

四条已观测类型的潜在有效数包含已知待激活第四条，当前激活有效数另记。原阈值开关改为低优先级提示。双爆默认受到静态模板保护。

整件仲裁按照数据检查、物品保护、模板保护、逐角色价值、用途覆盖及状态确认处理。输出保留、可作素材、建议试强化、需核对资料，并记录 `reasonCode`、`scopeCoverage`、`dataConfidence`、`modelRange` 和版本。

确认用途范围后，全部用途低价值仍需核对此件未锁定、未装备。当前OCR没有可靠的锁定图标识别，因此提供玩家逐件确认。返回游戏读取新帧会清除物品确认，避免两件相同属性的物品共用确认。改变来源或培养名单会清除用途范围确认。已强化物品继续计算分布，已有投入作为保留复核理由。

初始三词条+0第一次随机信息在+8，四词条在+4。试强化属于行动建议，强化资源成本和最优停止策略待后续加入。

## 自定义保护规则

`assets/decision-rules.json`沿用schemaVersion 1和rules数组。内置双爆保护始终生效，可额外添加保护规则。

```json
{
  "schemaVersion": 1,
  "rules": [
    { "id": "em-recharge", "type": "protect-stats", "keys": ["mastery", "recharge"], "reason": "精通充能备用", "enabled": true }
  ]
}
```

支持的键为 `hpPlus/atkPlus/defPlus/hp/atk/def/mastery/recharge/cpct/cdmg`。同规则中的键需要全部命中。未知规则类型、重复ID和非法键会在加载时提示格式错误，规则由仲裁器实际执行。部署保留运行目录已有的自定义文件。

## 验证与部署

`node tools/verify-all.mjs`覆盖原有OCR与数据链，以及PMF穷举、均值方差、严格尾概率、三四条随机占优、确定激活、缓存、自由位与2+2、四种建议和状态确认。

可执行只读个人资料回放，报告路径须位于源码目录外。

```powershell
node tools/verify-personal-data.mjs E:/BetterGI/User/JsScript/ArtifactStrongbox E:/BetterGI-Dev/validation/ArtifactStrongbox-0.10.0-personal.json
```

使用源码目录的deploy工具同步运行文件，部署前备份整个旧目录，保留账号、培养名单、日志、迁移备份及自定义规则。部署标记记录提交、dirty状态与实际文件哈希，支持当前未提交的源码。部署后重新运行JS任务加载新版。
