# 拟培养角色选择（0.8.1）

更新时间：2026-10-27。先在BGI刷新脚本配置，填写与角色录入时相同的“用户标识”。最新完整规则见 [三合一候选与推荐数据](strongbox-recommendations.md)。

普通运行直接显示三合一遮罩，不强制先选择培养角色。按F7切换交互，点击“选择拟培养角色”打开按元素分类的独立宽面板；支持元素标签、中文/全拼/首字母搜索、勾选和清空，自动按账号保存；再次F7返回游戏。默认合并“适配套装角色”和“用户培养角色”，还可开启沙/杯/冠“匹配主词条”来源。关闭一个来源不会排除从其他已开启来源命中的角色。

新版遮罩只展示当前账号已录入的角色，名字缺少本地评分规则时仍可选，结果明确显示“缺少评分规则”而不伪造分数。旅行者显示为“旅行者（元素）”，只列账号已有该元素记录的分支，兼容旧名单标签，不区分男女。

培养名单可以为空，仍可通过推荐匹配候选。选中角色的默认规则及已有手工分支一并参与评分；显示前20%和前80%分位数，移除理论最高分与分配，不再截断五行。不同用户标识使用独立文件，选择不会修改现装仓库：

- UID标识：`data/accounts/uid-<UID>.training.json`。
- 自定义标识：与仓库相同的编码文件名，后缀为`.training.json`。
- 文件包含账号标识、角色名列表、更新时间。主遮罩仅允许选择当前账号已录入名字；所有来源均关闭或没有命中时显示无候选，不退回全角色评分。

原有BGI“选择拟培养角色”独立入口仍保留：勾选运行后打开旧选择窗口，保存后本次结束；“运行角色仓库录入”仍优先。独立窗口可预设评分库其他名字且要求至少一位，但未录入名字不参与新版三合一推荐候选。日常修改建议直接使用遮罩内的角色表。

套装推荐和主词条推荐用来匹配候选，推荐使用率不会乘入评分。0.9.0的颜色标签使用副词条推荐秩及原规则对照现装；数字分位列仍保留原评分。详细比较前提和保守概率线见 [逐角色取舍](role-assessment.md)，不联网追踪“主流角色”。

已通过离线导航模拟、真实参考图OCR输出解析、动态筛选入口及HTML通信测试，并用本机Edge渲染预览核对布局。尚需BGI游戏内验证F7交互和滚动。本次开发对账号仓库只读。
