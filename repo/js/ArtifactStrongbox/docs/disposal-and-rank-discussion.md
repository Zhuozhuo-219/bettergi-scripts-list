# 取舍、套装约束与推荐顺序评分讨论

2026-10-28：部分讨论已在0.9.0实施为逐角色标签，参见 [实现范围与试行阈值](role-assessment.md)。整件综合结论、容量成本及完整配装优化仍未启用。下文保留当时方案推理。

记录：2026-10-27。本文件只讨论方案；0.8.1没有修改候选来源、随机强化或运行时评分权重。

## 三种候选来源回答的问题不同

培养角色表示个人目标；套装适配表示游戏推荐中的套装用途；主词条适配表示该部位的散件用途。来源命中用于说明“给谁看”，不能直接推出“能替换谁”。同一角色命中多个来源也不应重复加分，套装使用率不作为评分乘数。

来源的显示开关也不应被默认为“其余角色都没有保留价值”。未来给出取舍结论前，应明确评估范围是仅个人培养目标，还是包含套装/主词条潜在用途；界面隐藏的来源不能被悄悄解释成全账号排除。

建议对每个候选角色另给用途状态：可直接替换、需配套保留、资料不足。当前可直接替换需要可靠的五部位现装、允许的主词条和替换后的套装约束；为未来套装保留则评价目标配装，不能宣称已提升当前装备。

本账号实际录入示例：纳西妲为四深林加绝缘杯；千织为四黄金剧团加流浪杯；芙宁娜为四千岩加宗室冠。黄金剧团适配芙宁娜的推荐使用率89.4%，但推荐适配不等于替换当前千岩杯后仍保留四千岩。

## 第一阶段：固定其他四件，判断单件替换

对当前五件逐套计数。替换部位p、旧套装A、新套装B时：

`替换后件数[套装] = 当前件数[套装] - [旧件属于该套] + [新件属于该套]`。

将已有套装效果变成最低件数约束，而不是锁死每件物品的套装身份：

- 当前四件套A：要求替换后A≥4。
- 当前两件A＋两件B：要求替换后A≥2且B≥2。
- 五件A只须保留四件效果，所以换任意一件成散件仍满足A≥4；三件A＋两件B中A的第三件也属于可替换余量。
- 某部位缺失、装备者未知或历史基准过期时，不补全套装件数，不认定为可直接替换。

例如纳西妲的绝缘杯可以换成另一套杯而仍保留四深林；深林花换成其他套花则变三深林，不能列为保留原套装的直接提升。空之杯并非天生占用唯一散件位，哪一部位可散取决于其余四件；沙、冠也可成为散件。

还需区分“保持现有配装”与“转为目标配装”。若用户计划把芙宁娜从千岩用途改为黄金剧团用途，不能要求新目标始终保留千岩；应另设目标四黄金剧团约束。角色名本身不能区分这两种用途。

第一阶段可默认保护当前已生效套装。主词条相同且套装效果保持时，比较才最容易解释；主词条从生命杯改成水伤杯等变化，单靠副词条加权分不足以证明提升，应分别按允许主词条用途比较或标注需确认。

## 第二阶段：组合成套需要可用物品池

当前录入主要是各角色现装，不能证明仓库里有没有其余三件黄金剧团。单件不满足直接替换，不等于未来不能成套。先保留“需配套”状态即可，不应将其写成无用。

后续若录入仓库或用户指定备选池，可按五部位各选一件、套装件数达标、主词条允许等约束枚举组合；比较“限制必须带当前胚子的最佳配装”和“不带它的最佳配装”。多个角色同时安排时还要禁止同一件实物重复占用。OCR字段指纹不是可靠唯一ID，旅行者不同元素记录也可能对应同一批实物，因此跨角色物品去重需要额外设计。

## 用模拟结果比较现装

只对通过套装/主词条条件的用途计算`Δ = 候选+20得分 - 同用途现装得分`，并直接统计`P(Δ > 最小提升阈值)`。这比看到前20%分数高就保留更有针对性。前20%/前80%也可改为同一基准下的增量展示；概率须从样本计数，不能拿某个分位值冒充概率。

现装未满级时应明确比较基准：与现装当前值相比只是“候选强化后的预期变化”，不能混称同培养成本下更优。也可另行预测现装至+20形成对照，方案尚未选择。

“小概率大幅提升”“大概率微幅提升”“当前不可直接替换但目标套装可用”是不同决策，不能仅以一个总分排序解决。保留概率阈值、最小提升幅度和素材紧缺程度应由用户策略决定，本轮不设置默认丢弃线。结论只覆盖已选择或开启匹配的用途。

## 推荐顺序可以转成秩权重，但先统一数值单位

“暴击率和暴击伤害权重相等”可解释为一档相同品质的强化收益权重相等，不能解释为1%暴击率等于1%暴击伤害。先用各属性最高单次档位归一化：`u_i = 副词条终值 / 该属性最高单次档位`。当前本地表暴击率最高3.89、暴击伤害7.77、生命百分比5.83、充能6.48。

归一化包括初始词条及后续强化；主词条作为部位/用途条件单独处理，不加入固定高额底分。生命值百分比与固定生命值是不同键，不能因为名字相近继承相同权重。

推荐列表只提供顺序，没有相邻属性的真实收益比例。可试行“并列双爆组＋稠密秩”，再选择权重函数。双爆相邻时合并成一组；若被充能/精通隔开，单凭列表无法同时保留原顺序和强制双爆同权，应提示冲突或指定用途模板。

本账号已录入的实际追加属性：

| 角色 | 推荐顺序 | 合并双爆后的秩组 | 线性整数示例 |
| --- | --- | --- | --- |
| 芙宁娜、夜兰 | 暴伤、暴率、生命%、充能 | 双爆 → 生命% → 充能 | 暴率3、暴伤3、生命%2、充能1 |
| 纳西妲 | 精通、充能、暴伤、暴率 | 精通 → 充能 → 双爆 | 精通3、充能2、暴率1、暴伤1 |
| 千织 | 暴伤、暴率、防御% | 双爆 → 防御% | 暴率2、暴伤2、防御%1 |

设有效秩组共m组，线性权重为`W_i=m-rank_i+1`。不同角色推荐项数不同，原整数权重不能直接做横向总分比较；可除以该角色最大权重，使用`S=Σ(W_i/W_max)×u_i`，使各角色第一优先级的最高档词条统一为1分。芙宁娜的权重因此为1、1、2/3、1/3；千织为1、1、1/2。

如认为第一优先级应明显更重要，可讨论指数秩：三级组用整数4、2、1，归一化为1、1/2、1/4。线性3、2、1与指数4、2、1均为人为赋距，不能宣称是推荐列表直接给出的比例。本轮不决定采用哪一种，也不修改旧分数。

充能达到需求后的边际价值、暴击溢出和不同武器/流派仍无法由这份顺序得出。秩分适合筛选潜力，不等于真实伤害。后续可为用途增加少量可选参数（目标套装、允许主词条、充能需求），无需一开始完整识别武器/命座；无参数时不擅自推断精确阈值。

建议后续试行方向：先有套装与主词条可行性，再用推荐顺序产生标准化词条分，最后统计相对于可靠现装的提升概率。当前只记录该方向，等待进一步讨论。
