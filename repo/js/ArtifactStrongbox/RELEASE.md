# 发布说明：0.9.3

整理日期：2026-10-29。本次为发布前文档和文件职责整理，**版本号仍为0.9.3，运行代码、HTML、设置默认值、评分规则及账号数据均不修改**。使用说明见 [README](README.md)。

## 分发包内容

压缩包解压后应只有一层 `ArtifactStrongbox/`，将该目录放入 `BetterGI/User/JsScript/`。

| 内容 | 处理 |
| --- | --- |
| `main.js`、`manifest.json`、`settings.json` | 必须包含，保持原样 |
| `utils/` | 全部包含，含vendor快照、来源与许可 |
| `assets/` | 全部包含，含HTML、字典、动作JSON及 `images/main-ui.png` |
| `README.md`、`CHANGELOG.md`、`RELEASE.md`、`docs/` | 建议包含，提供操作、规则与维护说明 |
| `data/accounts/README.md` | 可包含，其他账号文件不带入新用户包 |
| `package.json`、`tools/` | 开发源码可包含；普通运行包无需Node工具 |
| `reference-images/` | 保留在本地开发目录，默认不分发 |

不要直接压缩整个正在使用的项目目录。按上表复制运行必需文件到新的暂存目录后打包；不要通过删除原目录中的数据来制作干净包。

## 默认排除项

- `data/accounts/` 内所有实际账号、培养名单、pending及backup文件。
- `data/logs/`、`data/name-migrations/` 内的运行日志、修正报告和原始备份。
- `tools/previews/` 中生成的HTML和图片，可能含账号角色资料。
- `reference-images/` 与 `tools/fixtures/` 中个人画面、姓名和OCR样本，公开源码前另行审阅脱敏。
- 本机键鼠录制、依赖缓存、临时环境、发布暂存目录及旧压缩包。

`.gitignore` 只帮助避免提交本地数据，**不会自动从手工压缩包排除文件，也不会移除已经被Git跟踪的内容**。

## 升级与已有数据

升级前备份 `data/` 以及自己修改的 `assets/character-profiles.json` 和 `assets/decision-rules.json`。新包不应携带他人账号文件；解压覆盖代码时保留本地用户资料，不清空目录。

用户标识和账号数据路径保持不变。培养名单按账号持久化，遮罩来源／套装限制开关仍在每次运行恢复默认。换装后的现装更新需要关闭跳过选项重新录入。

## 验证与待验收范围

发布前在完整开发工作区执行 `node tools/verify-all.mjs`，并检查文档链接、入口文件、资源路径与上游许可。普通运行包没有 `tools/` 时无需执行此命令。

离线测试不能替代游戏内验收。当前仍建议以试行版分发，实际使用环境需确认：

1. BGI发现脚本、设置保存、启动与停止清理。
2. 当前屏幕尺寸下的首次C导航、姓名稳定性与五部位装备归属。
3. 未装备部位、推荐套装弹窗、异常中断和角色循环。
4. F7交互、按元素搜索、来源筛选与套装约束切换。
5. 三合一物品切换后清除旧结果，非0级红名、三色计数及日志与界面一致。

不将用户部分测试或浏览器预览表述为全账号、全环境验收通过。本次文档整理不改变这些验证范围。
